# سباق المدينة — بناء APK من GitHub

## الملفات
- `index.html`  ← اللعبة (ارفعه في أول الريبو).
- `build-apk.yml` ← لازم يتحط في المسار `.github/workflows/build-apk.yml` (الخطوات تحت).
- `server.js` ← للعب الجماعي بس (على جهاز الهوتسبوت)، مش لازم يترفع.

## الخطوات
1. على GitHub اعمل ريبو جديد (Public أو Private).
2. من «Add file ← Upload files» ارفع `index.html` فقط واعمل Commit.
3. «Add file ← Create new file» واكتب في خانة الاسم بالظبط: `.github/workflows/build-apk.yml`
   (لما تكتب `/` بيعمل فولدر لوحده)، والصق جواه محتوى `build-apk.yml`، واعمل Commit.
4. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو هيشتغل لوحده بعد الـ Commit).
5. بعد ~6-10 دقايق افتح العملية الناجحة ونزّل الـ Artifact اسمه **city-race-apk** (ملف zip فيه app-debug.apk).
6. فك الضغط وثبّت الـ APK (اسمح بالتثبيت من مصادر غير معروفة).

## اللعب الجماعي (بعد ما التطبيق يشتغل)
- جهاز الهوتسبوت: Termux ← `pkg install nodejs` ← حط `server.js` في فولدر ← `node server.js`
  (السيرفر مش محتاج `index.html`، لأن التطبيق جواه اللعبة). هيطبع عنوان زي `192.168.43.1:8080`.
- كل الأجهزة (حتى الهوست) تتصل بالهوتسبوت، وفي التطبيق: لوبي ← العب مع زمايلك ← اكتب العنوان ← اتصل.
- أول واحد بيتصل بيبقى الهوست وهو اللي يضغط «ابدأ السباق».
